## 📌 Project Overview
A global economic analysis project examining GDP per capita across countries, identifying economic growth patterns, regional disparities, and clustering similar economies. Combines Python-based statistical analysis with Power BI geospatial dashboards.

## 🗂️ Files
| File | Description |
|------|-------------|
| GDP Per Country Project.ipynb | Python analysis & visualization notebook |
| GDP Per Country.csv | Country-level GDP dataset |
| Visualization.pbix | Power BI geospatial dashboard |

## 🛠️ Tools & Technologies
- **Python** (Pandas, Matplotlib, Seaborn, Scikit-Learn) — EDA & clustering
- **Power BI** — Interactive geospatial maps & dashboards
- **Jupyter Notebook** — Analysis environment

## 📊 Key Analysis
- GDP per capita ranking and comparison by country & region
- Year-over-year economic growth rate analysis
- K-Means clustering of economies by development stage
- Geospatial mapping of global economic distribution
- Correlation of GDP with social indicators

## 💡 Key Insights
- Clustered countries into distinct economic development tiers
- Visualized stark GDP disparities between global regions
- Identified fastest-growing economies over the analysis period
